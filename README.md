# .vim

Personal Vim configuration focused on programming and command-line workflows.

## Highlights

- Four-space indentation and filetype-aware syntax settings
- Persistent folds and views between editing sessions
- Dedicated backup and swap directories
- Keyboard mappings for navigation and common editing actions
- Helper functions for compiling and running C and assembly files

## Repository layout

- `.vimrc`: primary Vim configuration
- `.backups/`: directory configured for backup files
- `.swap/`: directory configured for swap files
- `view/`: persisted Vim view data
- `.gitignore`: exclusions for generated and local files
